# ただ雲は流れて ／ WHY I FLY ─ イラスト版

### ▶ 遊ぶ： https://katomi95.github.io/why-i-fly-art/

> SVG 版（背景・立ち絵をすべて CSS と SVG で描いたオリジナル）は
> **https://katomi95.github.io/why-i-fly/** です。シナリオと進行は完全に同一で、絵だけが違います。

敗戦間近の、ある架空の国。
特攻を命じられた十代の少年兵と、それを冷静に否定しつづける女性の、五日間の会話劇。

**プレイ時間：約15〜20分**
HTML / CSS / JavaScript のみ。外部ライブラリなし。PC・スマートフォン対応。
全16枚の一枚絵は OpenAI の画像生成（gpt-image）で制作しています。

---

## 作品について

これは戦争ゲームではありません。戦闘描写・敵の撃破・爆発は一切ありません。

描いているのは、
**一度は死を受け入れた人間に、あとから生きたい理由が生まれてしまう**
という悲劇です。

主人公は最後に出撃しますが、それは「尊い自己犠牲」でも「立派な死」でもありません。
死ぬ理由をすべて失ってなお、過去の覚悟と仲間の死と、自分が生きてきた文脈から
歩き出せなかった人間の話として描いています。

> 人間は、正しいことを理解したからといって、必ず正しい選択をできるわけではない。

登場する国家・軍隊・基地・作戦・人物・兵器はすべて架空であり、
実在の戦争、実在の作戦、実在の組織とは一切関係ありません。

## 遊びかた

画面のどこかをクリック／タップで読み進めます（`Space` / `Enter` も可）。
文章表示中にクリックすると、その行を最後まで表示します。

セーブ・ロード・設定はありません。一度きりの通し読みとして作られています。
左上の `♪` で音の ON / OFF を切り替えられます（音はすべて Web Audio による生成音です）。

意図的な「間」が多く挿入されています。何も起きない数秒は演出です。

---

## WHY I FIGHT

画面の隅には、主人公が自分に言い聞かせている五つの理由が表示されます。

```
WHY I FIGHT
  国を守る
  家族を守る
  仲間との約束
  軍人としての責務
  逃げない
```

会話が進むごとに、これらは一つずつ否定され、取り消し線が引かれていきます。
最後には、何も残りません。

## ファイル構成

```
.
├── index.html          画面構造
├── style.css           背景・UI・表示用フォント
├── story.js            シナリオデータ（全 896 コマンド）
├── script.js           進行エンジン・Web Audio
└── assets/
    ├── bg_*.jpg        一枚絵 16 枚（1600x900 / JPEG q86）
    └── fonts/          表示用フォント（同梱・サブセット済み）
```

素材は合計約 3.2 MB。音は Web Audio による生成音のみで、音声ファイルはありません。

**立ち絵レイヤーは持ちません。** 人物が登場する場面は、人物ごと描かれた一枚絵に背景を差し替えます
（`bg_road_eve_iris` / `bg_road_dusk_iris` / `bg_road_night_iris` / `bg_cry_close`）。
切り抜き素材を重ねないので、髪やコートの隙間に抜き残りが出ることがありません。

ビルド不要・依存なしなので、そのまま GitHub Pages に置けば動きます。

### 公開

リポジトリの Settings → Pages で `main` ブランチの `/ (root)` を公開すると、
`https://katomi95.github.io/why-i-fly-art/` で遊べます。
ビルド不要・依存なしなので、リポジトリをそのまま置くだけで動きます。

### ローカルで動かす

```bash
python -m http.server 8232
```

## シナリオ拡張のしかた

`story.js` は上から順に実行されるコマンドの配列です。

| 記法 | 意味 |
|---|---|
| `N('地の文')` | ナレーション（3行まで積み重なる） |
| `R('台詞')` / `I('台詞')` | 主人公リオ／イリスの台詞 |
| `D('話者','台詞')` | その他の人物 |
| `BG('road_eve')` | 背景切り替え（クラス名は `style.css` の `.bg-*`） |
| `CH('iris','cry')` / `CH(null)` | 人物入りの一枚絵に切り替え／素の背景に戻す |
| `W_(1200)` | 間（ミリ秒／スキップ不可） |
| `BIG('DAY 1', 2200)` | 全画面の大文字表示 |
| `CRACK('kuni')` / `STRIKE('kuni')` | WHY I FIGHT に亀裂／取り消し線 |
| `NOTE([...])` | 手紙・紙切れの表示 |
| `CHOICE([...], 5000)` | 制限時間つき選択肢 |
| `SFX('takeoff')` / `BGM('stop')` | 音 |

台詞の第2引数に `{ slow:true }` で表示速度を落とし、
`{ auto:2600, lock:true }` でクリックを受けつけず自動で送ります
（終盤の「行くな」の連続に使用）。

## 画像について

一枚絵 16 枚は OpenAI の画像生成モデルで制作しました。
人物が入る 3 枚は、**先に描いた無人の背景を編集して人物だけを描き足して**います。
そのため無人版と人物版で場所・光・構図が完全に一致し、切り替えても場面が変わって見えません。
最後の対面だけは寄りの一枚絵に切り替わります。

実在の国家・軍隊・作戦を再現しないという方針に合わせ、
**文字・記章・国旗・国籍マークが画面に出ないように**生成しています。
航空機にも一切のマーキングはありません。

## フォント

`DAY 1` / `WHY I FLY` / `END` などの欧文表示に **Cinzel**、
タイトルと `出撃命令` の和文表示に **Shippori Mincho B1** を使っています。
どちらも SIL Open Font License 1.1 で、**実際に使う文字だけにサブセットして同梱**しています
（合計 18 KB、外部からの読み込みはありません）。ライセンス全文は `assets/fonts/OFL-*.txt`。

本文は引きつづき OS 標準の明朝を使っています。
